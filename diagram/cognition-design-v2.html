mem0ress Cognition Architecture

基于纯文本的心智模型、瞬态位面与外部任务级 Harness 系统

1. 认知解耦宏观架构 (The CPU-RAM-Disk Model)

将 Agent 视作 CPU，mem0ress 视作高频状态内存 (RAM)，外部知识库视作静态硬盘 (Disk)。系统严格禁止硬盘直接写入内存，必须经过 CPU 的知识蒸馏。

3. 任务级 Harness 与失败补丁流 (3-Tier Harness Validation)

短路评估设计：从极低成本的文本状态解析，到外部脚本跑测，最后才调用大模型进行昂贵的“自然语义 Picture 验证”。
