# verify.md

`verify.md` 是验证协议 + 检验结论的合并文件。每个 Task 创建时生成（空文件），随着任务执行逐步填充。

## 核心设计原则

1. **验证方式通过交互式对话确认，不追求预先全覆盖**
2. **Constraint 和 Requirement 的验证方式由人确认后写入 `[.]` / `(.)` / `{.}`**
3. **检验结论由 Verify Agent 执行后追加，不覆盖历史**
4. **Tier 3（语义对齐）通过人机对话验证，不写入 verify.md**

## 文件结构

```markdown
# verify.md

## Constraints（约束验证）
## Requirements（需求验证）
## 验证记录
```

---

## Constraints

每条 Constraint 对应 task.md 中的一条 `C-N`。

### 状态标记

| 标记 | 含义 | 说明 |
|------|------|------|
| `[]` | 待讨论 | 尚未确认验证方式 |
| `[.]` | 已确认 | 通过交互式对话确认验证方式，人写入 |
| `(.)` | 已执行 | Verify Agent 已执行验证并通过 |
| `[×]` | 违规中 | Constraint 已被违反，正在等待处理 |

### 格式

```markdown
### C-1: [约束描述]

- **验证方式**: [ ] 待讨论 / [.] 对话确认
- **验证时机**: Tier 0（检验触发时）
- **验证结果**: [×] / (.) / [.]
- **备注**:
```

---

## Requirements

每条 Requirement 对应 task.md 中的一条 `R-N`。

### 状态标记

| 标记 | 含义 | 说明 |
|------|------|------|
| `[]` | 待讨论 | 尚未确认验证方式 |
| `[.]` | 已确认 | 通过交互式对话确认验证方式，人写入 |
| `(.)` | 已执行 | Verify Agent 已执行验证并通过 |
| `{.}` | 已跳过 | Agent 主动跳过，说明理由，不执行验证 |

### 格式

```markdown
### R-1: [需求描述]

- **验证方式**: [ ] 待讨论 / [.] 对话确认
- **验证方式说明**: [描述具体如何验证]
- **验证时机**: Tier 2（检验触发时）
- **验证结果**: (.) / {.} / [.]
- **备注**:
```

### 验证方式类型

| 类型 | 前缀 | 说明 |
|------|------|------|
| checked | `[]` / `[.]` | 交互相验证，Verify Agent 向人提问，人回答 yes/no |
| command | `()` / `(.)` | 命令式验证，Agent 执行命令，以退出码判断结果 |
| skip | `{}` / `{.}` | 主动跳过，记录理由，不执行验证 |

## 验证记录

每次检验触发后追加，不修改历史。

### 格式

```markdown
---

### 验证记录 {N.M}

**时间**: {YYYY-MM-DD HH:MM:SS}
**触发者**: Verify Agent
**结论**: PASSED / FAILED

#### Tier 0 — 约束验证
| Constraint | 结果 |
|------------|------|
| C-1 | (.) |
| C-2 | [×] |

#### Tier 1 — 进度验证
- Todo 1/3 完成
- 子任务: 2/2 完成

#### Tier 2 — 需求验证
| Requirement | 结果 | 说明 |
|-------------|------|------|
| R-1 | (.) | |
| R-2 | (.) | |

#### Tier 3 — 语义对齐
- **验证方式**: 人机对话
- **结论**: PASSED / FAILED / SKIPPED
- **说明**: [具体对话结论]
```

---

## 写入规则

1. **只有人才能写入 `[.]` / `(.)` / `{.}`** — 验证方式一旦确认，由人写入
2. **Agent 只能写入 `[]` / `()` / `{}`** — 待讨论状态的维护
3. **Verify Agent 只追加写验证记录** — 不修改历史
4. **Tier 3 不写入 verify.md** — 通过人机对话验证，结论记录在验证记录中
